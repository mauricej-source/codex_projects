# State of Florida Data Heatmaps

This project produces a single self-contained HTML page that visualizes Florida county-level infrastructure data as interactive heatmaps. The generated page currently includes three data layers:

- Electrical percent outage
- Electrical energy consumption
- Natural gas consumption

All data is embedded directly into the output HTML, so the page can be opened locally in a browser without a web server or external runtime dependencies.

## Project Output

The main output file is:

- `C:\ws_openai_codex\florida_county_energy_map.html`

This page is generated from local Excel workbooks and county boundary geometry pulled by the generator script.

## End User Experience

When an end user opens the generated HTML page, they can expect:

- A left-hand navigation panel with data layer controls
- A Florida county map rendered as a choropleth heatmap
- A year selector for the electric energy and natural gas layers
- An active-layer summary that updates with the selected layer and year
- A legend that updates with the selected layer
- Hover tooltips that show only the active layer’s county-specific data
- Zoom in, zoom out, reset view, mouse wheel zoom, and drag-to-pan behavior
- A footer panel with source citations for the displayed datasets

## How To Use The Page

1. Open `C:\ws_openai_codex\florida_county_energy_map.html` in a browser.
2. Use the `Data Layer` controls to switch between outage, energy consumption, and natural gas consumption.
3. For energy or natural gas, use the year dropdown beneath the layer controls to switch between available years.
4. Hover over any county to see the active layer’s county-level details.
5. Use the `+`, `-`, and `Reset view` controls to adjust map framing.
6. You can also zoom with the mouse wheel and drag the map to pan.

## Source Summary

- County boundaries: Florida county boundary service published by the Florida Department of Agriculture and Consumer Services
- 2026 outage data source: [poweroutage.us](https://poweroutage.us/use-our-data/utilities)
- 2017 to 2036 energy consumption by county data source: [maps.nlr.gov SLOPE viewer](https://maps.nlr.gov/slope/data-viewer)
- 2017 to 2036 natural gas consumption by county data source: [maps.nlr.gov SLOPE viewer](https://maps.nlr.gov/slope/data-viewer)

## Build And Regenerate

The project is generated by:

- `C:\ws_openai_codex\scripts\generate_florida_outage_map.py`

To regenerate the HTML:

```powershell
python C:\ws_openai_codex\scripts\generate_florida_outage_map.py
```

That command rewrites:

- `C:\ws_openai_codex\florida_county_energy_map.html`

## Requirements

Python dependencies used by the generator:

- `openpyxl`
- `requests`

If needed, install them with:

```powershell
python -m pip install openpyxl requests
```

## Start The Project

There is no application server to start for normal use.

To use the project:

1. Regenerate the HTML if the source workbooks changed.
2. Open `C:\ws_openai_codex\florida_county_energy_map.html` in your browser.

If the browser appears to show stale behavior after a regeneration, reopen the local HTML file or do a hard refresh.
