Analyze the uploaded vehicle dashboard image and extract only the requested dashboard data into an Excel-ready table.

Create one row per uploaded dashboard image.

Use these columns in this exact order:

datetimestamp_ms | datetime | Vehicle Brand | Gear Selection | Speed | Odometer | Fuel Level

Column requirements:

1. datetimestamp_ms
   - Use a Unix timestamp in milliseconds.
   - This should act as the unique identifier for the row.
   - If the image contains EXIF capture time, use that.
   - If EXIF capture time is not available but the filename contains a timestamp, use the filename timestamp.
   - If neither is available, use the current extraction timestamp.
   - If processing multiple images with the same timestamp, increment each additional row by 1 millisecond to keep the value unique.

2. datetime
   - Human-readable version of datetimestamp_ms.
   - Format exactly as: mm/dd/yyyy:hh:mm:ss
   - Example: 05/02/2026:20:29:12

3. Vehicle Brand
   - Extract the visible vehicle brand from the dashboard image.
   - Use exact visible text when available.
   - If unclear, write “unclear”.

4. Gear Selection
   - Extract the visible gear selection.
   - Examples: P, R, N, D, 1, 2.
   - If unclear, write “unclear”.

5. Speed
   - Extract the visible speed.
   - Use the digital speed readout if available.
   - Return the value as a number only.
   - Assume MPH unless another unit is visible.
   - If unclear, write “unclear”.

6. Odometer
   - Extract the visible odometer mileage.
   - Return the value as a number only.
   - Assume miles if “mi” is visible.
   - If unclear, write “unclear”.

7. Fuel Level
   - Estimate the fuel level from the fuel gauge.
   - Return as a percentage number only, such as 45.
   - If the fuel gauge is not visible or cannot be estimated, write “unclear”.

Rules:
1. Output only a clean table that can be copied directly into Excel.
2. Do not include extra explanation outside the table.
3. Use exact visible text when possible.
4. For estimated values, still place the estimate directly in the appropriate column.
5. Do not add extra columns.
6. After generating the table, save it as an Excel file named dashboard_summary.xlsx.
